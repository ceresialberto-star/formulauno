# formulauno
Questa web app sulla Formula 1 permette di seguire il campionato con risultati aggiornati, classifiche di voi piloti che giocherete. Offre un’interfaccia per accedere prendendo i vostri dati e poi vi fara visualizare i vostri punti e tempio per arrivare prima in classifica con il vostro rispettivo pilota e scuderia che userte è molto semplice chiara e completa .
